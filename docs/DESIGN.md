# 题面与作图约定

给定按边界顺序排列的严格凸四边形 $ABCD$，用无刻度直尺和圆规，构造其内部及边界组成的均匀薄板的质心 $G$。

## 给定与输出

初始对象为四个顶点。允许顺时针或逆时针编号，以及任意平移、旋转、反射与正比例缩放。严格凸保证四个顶点互异、没有三个顶点共线，两条对角线唯一交于内部点 $E$。

薄板密度为任意正常数，面积为 $S>0$，目标定义为

$$G=\frac1S\iint_{ABCD}X\,\mathrm dA.$$

最终输出点 $G$。记 $M,N$ 分别为 $AC,BD$ 的中点，$V$ 为 $MN$ 的中点，则

$$V=\frac{A+B+C+D}{4}.$$

## 尺规操作

采用无刻度直尺与塌圆规。基础操作为经过两个已有不同点作直线，以已有点为圆心、经过另一个已有点作圆，以及取得已作直线和圆的有限实交点。允许精确判断点相等、共线、次序与侧别。

中点、垂直平分线及过点平行线采用经典有限尺规宏。[完整展开](ANSWER.md)

主构造保留原题的辅助圆与两条连接线。在某条对角线被另一条平分时，使用明确的三等分分支。平行四边形直接输出 $E$。每个分支均有固定有限步骤。

## 证明与展示

一般证明覆盖全部实坐标的严格凸输入。核验使用 SageMath 的精确实代数数域 `AA`，独立计算多边形的面积一阶矩。浮点数用于 Manim 显示。
